# MD//CONVERTER ⚡

A cyberpunk-themed Streamlit app that converts **PDF**, **PPTX**, and **DOCX** files to **Markdown** using [Microsoft MarkItDown](https://github.com/microsoft/markitdown).

## Features
- Upload multiple files of the same format at once
- Converts using Microsoft MarkItDown library
- Download each .md file individually or all as a .zip
- Cyberpunk UI with neon glow, scanlines and Orbitron font

## Supported Formats
| Input | Output |
|-------|--------|
| .pdf  | .md    |
| .pptx | .md    |
| .docx | .md    |

## Setup

pip install -r requirements.txt
streamlit run app.py
